# Heart-Failure-Prediction


## Overview 

This project was completed as part of the Week 2 assignment for the Data Science Internship Program at AnalystLab Africa. It explores employee attrition and highlights key patterns to identify factors influencing workforce turnover.  
  
## Business Problem

Employee attrition creates financial and operational challenges. Replacing employees requires recruitment, onboarding, training, and time before new hires become fully productive. Organizations often struggle to identify why employees leave, which departments are most affected, and whether retention initiatives are effective. This project addresses those questions using data-driven analysis.

## Objectives

The main objective of this project is to analyze employee data to understand the factors contributing to attrition. By examining trends in key variables, the project aims to provide insights that can support better workforce planning and employee retention strategies.

## Dataset 📊 

IBM HR Analytics Employee Attrition & Performance

## Tools and Libraries📚  

The project was carried out using the following tools and libraries:

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Methodology

The analysis followed these steps:

1. Loaded and inspected the dataset.
2. Cleaned the data by checking for missing values, null values, duplicated values and descriptive analysis.
3. Performed exploratory data analysis to understand the structure of the data.
4. Visualized key relationships between attrition and other variables.
5. Identified patterns and trends that may influence employee turnover.

## Key Findings 📉 

The analysis revealed several useful insights into employee attrition.  The company has a relatively stable workforce, with attrition affecting a minority of employees. However, it was also discovered that younger employees have a high tendency of leaving the organization. Incentives such as performance bonuses should be introduced for employees with lower monthly income

## Visualizations 💹 

The project includes charts and graphs that illustrate the relationship between attrition and selected features. These visualizations make it easier to identify trends and compare employee groups across different categories.

## Conclusion

This project provided a clear view of the factors associated with employee attrition. The findings can help organizations better understand workforce behavior and make informed decisions to improve employee retention.

## Recommendations

Based on the analysis, the following recommendations are suggested:

- Improve employee engagement and job satisfaction.
- Review compensation structures to ensure competitiveness.
- Strengthen workplace support and communication.
- Monitor employees who may be at higher risk of leaving.
